📌 Description

MathLib est une bibliothèque Python contenant des fonctions mathématiques utiles.

Elle permet de faire des calculs, de la géométrie, de la trigonométrie et des conversions d'angles.

🚀 Utilisation

Importer le module : 

import MathLib.calcul as calcul

Exemple : 

import MathLib.calcul as calcul

resultat = calcul.additionner(10,20,30)

print(resultat)

Résultat : 

60

📚 Fonctions disponibles

➕ Addition

calcul.additionner(10,20,30)

Additionne plusieurs nombres.

➖ Soustraction

calcul.soustraire(100,20,10)

Soustrait plusieurs nombres.

✖ Multiplication

calcul.multiplier(2,3,4)

Multiplie plusieurs nombres.

➗ Division

calcul.diviser(100,2,5)

Divise plusieurs nombres.

⬛ Carré

calcul.carre(5)

Retourne le carré d'un nombre.

🔥 Puissance

calcul.puissance(2,4)

Résultat : 16

√ Racine carrée

calcul.racine(25)

Résultat : 5

📐 Hypoténuse

calcul.pythagoreH(3,4)

Calcule l'hypoténuse d'un triangle rectangle.

📍 Distance entre deux points

calcul.pythagoreD(0,0,3,4)

Calcule la distance entre deux coordonnées.

📈 Trigonométrie

calcul.sin(angle)

calcul.cos(angle)

calcul.tan(angle)

Les angles sont en radians.

🔄 Conversion d'angles

calcul.degresVersRadians(90)

calcul.radiansVersDegres(3.14159)
